## 📊 项目介绍

DataBoard（数据看板）是一个开源的数据可视化大屏项目，旨在帮助开发者从零开始学习如何独立制作一个完整的数据大屏。

无论你是前端新手还是有经验的开发者，这个项目都会带你走完从需求分析、技术选型、界面设计到最终部署上线的全过程。

## ✨ 功能特性

- 🎨 **精美大屏设计** — 深色主题 / 科技感边框 / 动态特效
- 📈 **丰富的图表类型** — 柱状图、折线图、饼图、雷达图、地图等
- 🔄 **实时数据刷新** — 支持定时轮询与 WebSocket 推送
- 📱 **自适应分辨率** — 常用大屏分辨率适配（1920×1080 / 2560×1440 / 3840×2160）
- 🧩 **组件化架构** — 每个图表独立封装，即插即用
- 📦 **从零到一教程** —每一步都有详细的文档和代码注释

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/millxasn/DataBoard.git

# 进入目录
cd DataBoard

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 🛠 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React 18 / Vue 3 |
| 构建工具 | Vite |
| 可视化库 | ECharts / AntV |
| 样式方案 | CSS Modules / Less |
| 数据请求 | Axios |
| 部署方案 | Nginx / Docker |

## 📚 学习路线

1. **环境搭建** — 开发环境配置与项目初始化
2. **布局设计** — 大屏整体布局与网格系统
3. **主题定制** — 深色主题、边框特效、配色方案
4. **图表组件** — 逐一实现各类图表组件
5. **数据对接** — Mock 数据与真实 API 对接
6. **动态刷新** — 定时刷新与实时推送
7. **自适应方案** — scale 自适应与 rem 方案
8. **打包部署** — 构建优化与 Nginx 部署
9. **性能优化** — 渲染性能与请求优化
10. **进阶技巧** — 动画特效与交互增强
